# Laundry Mart

Laundry Mart is a responsive laundry service booking website built using HTML, CSS, and JavaScript. Users can add services to a cart, view the total amount, and place bookings. After successful booking, a confirmation email is send on the email id provided for booking.

## Features

- Responsive UI design
- Add/remove services from cart
- Dynamic total price calculation
- Booking form validation
- EmailJS booking integration

## Technologies Used

- HTML5
- CSS3
- JavaScript
- EmailJS
